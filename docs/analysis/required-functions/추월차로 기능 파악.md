# 미션 기능 파악

## 추월차로 구간(feat. 준서)

### 구상

추월차로 구간에서의 차의 움직임을 생각해보았는데 코딩하기 비교적 쉬울 것 같은 버전과 어려운 버전을 모두 생각해보았다. 어려운 버전을 생각한 이유는 아래에서 말한 쉬운 버전으로 하면 1차선과 3차선에 차가 조금 더 일찍 있는 경우는 극복하지 못할 것 같아서이다.

> 쉬운 버전
>
> 1. 추월 차로 구간을 인식하고 미션 state에 진입. (카메라는 비교적 내린 상태)
> 2. 정면의 차를 인식.
> 3. 정면의 차와 일정 거리가 되면 정지.
> 4. 카메라 각도를 위로 올려 좌, 우의 차량 감지.
> 5. 원활한 차선 인식을 위하여 다시 카메라 각도를 낮춘다.
> 6. 두 차선 중 하나를 택하여 진입. (기본 값으로 왼쪽 차선을 한다던지)
> 7. 직진 하다가 차선이 끝나게 되면 다시 가운데 차선으로 변경하여 미션 구간을 탈출한다.



> 어려운 버전
>
> 1. 추월차로 구간을 인식하고 미션 state에 진입.
> 2. 카메라를 약간 올린다. (평소 주행할 때의 카메라 각도로는 모든 차선을 볼 수 없을 것 같은 느낌)
> 3. 카메라를 이용하여 3차선을 구분하는 두 개의 차선을 인식한다.
> 4. 이를 바탕으로 주행하며 차가 없는 차가 없는 차선을 제외한다. (세 개의 차선을 생각해놓고 주행하다가 좌 우에 차량을 발견하면 해당 차선은 선택지에서 제외)
> 5. 정면의 차량을 발견하고 일정 거리가 되면 차량이 없는 차선을 선택하여 주행
> 6. 일정 거리 이상을 가고 측면 PSD 센서에 아무것도 감지되지 않으면 다시 가운데 차선으로 복귀
> 7. 추월차로가 끝나는 선을 발견하고 미션 검사 state로 복귀

### 필요한 기능

위와 같이 미션을 수행하기 위해 필요한 기능을 생각해보았다. 

* 차를 인식하는 기능 (색깔정도로 장애물인지만 판단)
* 정면의 차와의 거리를 인식하는 기능
* 차선을 인식하는 기능
* 차선을 변경하는 기능 (사륜 구동이 아니므로 다수의 테스트를 통해서 정면 차와의 거리가 얼마일 때 부드럽게 옆으로 갈 수 있는지 파악해야 할 것)
* 카메라 각도를 조절하는 기능 (이미 있음)
